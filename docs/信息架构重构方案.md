## 一、诊断：当前架构的核心问题

评审结论可以收敛为四条根因，其余现象都是它们的表现：

| 编号 | 问题 | 具体表现 |
| --- | --- | --- |
| P1 | **域归属错位**：功能没有放在"它所属的那个 Tab"里 | 「家当设置 / 待买清单 / 到期提醒 / 回收站」都在「我的」页，但它们是家当域的子页面；「记账分类」在「我的」页，是记账域的子页面 |
| P2 | **主 Tab 有名无实**：`家当` Tab 只是一个搜索列表 | 「家当」是 5 个主 Tab 之一，但页面内只有搜索与筛选，没有任何通往家当域其他页面的入口，域内闭环断裂 |
| P3 | **入口集中而重复**：「我的」退化成杂物抽屉 | 低频的「我的」页同时承载家当域 + 记账域 + 提醒域 + 数据管理四类入口，主次不分 |
| P4 | **命名与心智不一致**：同名不同物 / 同物不同名 | 家当域计数的口径分散在两个 ViewModel；记账页胶囊写「资产」，落地页标题却是「资产负债」；「到期提醒」（入口名）与「即将过期」（页面名）不一致 |

此外还有两个**实打实的缺陷**（已在上一轮修复）与一个**空态死胡同**（本轮收口）：

- 详情页删除入口不可达（`showDeleteDialog` 永远为 false）→ 已修复
- 家当设置页底部留出一整块空白（多减了一次底栏高度）→ 已修复
- 到期提醒空列表时没有任何出路 → 本轮补「去家当补效期」

## 二、设计原则

1. **域内闭环**：一个域的子页面，入口必须能在该域自己的 Tab 内找到；跨 Tab 的兜底入口可以保留，但不再是唯一入口。
2. **一物一入口主位**：每个子页面有且只有一个"主入口"，落在它所属的域里；其余位置若保留，只能作为弱化的快捷方式，不得喧宾夺主。
3. **计数随域走**：某个域的数量角标，由该域自己的 ViewModel 提供，避免同一口径在多处重复实现。
4. **命名一致**：入口名、页面标题、角标口径三者对齐同一套词。
5. **最小改动**：不新增路由、不重写页面，只做"入口搬家 + 标题对齐 + 空态出路"。

## 三、目标架构

### 3.1 主 Tab 与域的归属

```
┌─ 首页 Home      → 今天的事（提醒 / 纪念日 / 临期的聚合视图）
├─ 记账 Ledger    → 记账域根：流水 + 预算 + 统计 + 资产负债 + 分类管理
├─ 吃饭 Meal      → 吃饭域根：一周菜单 + 菜谱库
├─ 家当 Household → 家当域根：物品搜索筛选 + 家当设置 / 待买 / 到期 / 回收站
└─ 我的 Profile   → 只留"关于我"：提醒与纪念日 + 设置与数据
```

### 3.2 各域入口分布（调整后）

| 子页面 | 所属域 | 主入口（本域内） | 备注 |
| --- | --- | --- | --- |
| 家当设置 Category | 家当 | 家当页 · 域入口行「家当设置」 | 从「我的」移除 |
| 待买清单 ToBuy | 家当 | 家当页 · 域入口行「待买 n」 | 从「我的」移除 |
| 到期提醒 Expiry | 家当 | 家当页 · 域入口行「到期 n」 | 从「我的」移除 |
| 回收站 Trash | 家当 | 家当页 · 域入口行「回收站 n」 | 从「我的」移除 |
| 记账分类 LedgerCategoryManage | 记账 | 记账页页头胶囊「分类」 | 从「我的」移除 |
| 预算 / 统计 / 资产负债 | 记账 | 记账页页头胶囊（原有） | 「资产」→「资产负债」与落地页标题对齐 |
| 待办提醒 / 纪念日 | 提醒 | 「我的」页（原有，保留） | 「我的」的正牌内容 |
| 设置 / 局域网同步 / 导入导出 | 系统 | 「我的」页（原有，保留） | 「我的」的正牌内容 |

### 3.3 「家当」Tab 的目标结构

```
家当（标题 + 副标题）
└─ 域入口行： [家当设置] [待买 n] [到期 n] [回收站 n]   ← 本轮新增，导航用途
搜索栏（搜索物品、分类、位置或备注）
└─ 筛选胶囊行：[筛选] [在库] [待买] [已用完] [全部]      ← 原有，筛选用途
└─ 生效条件胶囊 → 结果列表 / 空态（重置筛选条件）
└─ FAB「录入家当」
```

视觉上用**暖色弱化胶囊**承载"导航"，与白底/选中态的**筛选胶囊**区分，避免两类胶囊混淆。

### 3.4 「记账」Tab 的目标结构

```
记账（标题 + 副标题）
└─ 页头胶囊行：[预算] [统计] [资产负债] [分类]   ← 「分类」新增，「资产」改名
固定月份条 → 汇总卡 → 预算条 → 账户 → 按日流水
└─ FAB「记一笔」
```

四枚胶囊横向可滚动，窄屏下不挤压标题。

### 3.5 计数（角标）的归属

| 口径 | 迁移前 | 迁移后 |
| --- | --- | --- |
| 待买数量 | ProfileViewModel | **SearchViewModel** |
| 临期数量（阈值取 `reminderDays`） | ProfileViewModel | **SearchViewModel** |
| 回收站数量（30 天内可恢复） | ProfileViewModel | **SearchViewModel** |
| 今日待办数量 | ProfileViewModel | ProfileViewModel（不变，属「我的」的提醒域） |
| 纪念日数量 | ProfileViewModel | ProfileViewModel（不变） |

## 五、验证与限制

- 本轮改动为纯 Compose / Kotlin 源码调整，未新增依赖、未改动 Room schema。
- 当前构建环境**只有 JRE（Temurin 21），没有 JDK（无 `javac`、未配置 `JAVA_HOME`）**，
  因此**无法执行 `gradlew` 编译验证**；改动已做静态校验（导入、符号、括号配对、调用点唯一性）。
- 待补 JDK 后执行：`gradlew.bat :app:assembleDebug`（或 `:app:compileDebugKotlin`）。
